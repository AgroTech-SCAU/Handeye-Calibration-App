# 功能规划

## 工程原则

- 相机数据、机器人位姿与标定求解相互解耦，保持独立输入接口
- 内参、标定板几何、坐标系和采样数据在每个项目内独立管理
- 已保存的样本可跨会话恢复，不以求解完成作为项目切换的必要条件
- 数据冻结、独立验证、异常诊断与强制切换优先保证可追踪性和可恢复性
- 只有完成安全条件检查后才允许向外部规划接口发送运动请求

## 后续维护

- 优化相机输入模式识别及分辨率、CameraInfo 和冻结参数的差异诊断
- 改善手眼矩阵及工具 Link 的几何一致性反馈和空间测量误差展示
- 保持项目迁移和数据导入导出格式稳定，避免隐式覆盖样本
- 简化界面文字，保留必要操作引导和独立错误信息
