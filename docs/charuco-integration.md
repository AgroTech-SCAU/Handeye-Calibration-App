# CharUco 标定板使用说明

CharUco 适合局部遮挡、不同视角的角点检测，角点通过唯一 ID 与板上坐标对应

配置时需明确方格列数与行数、方格实际边长、Marker 边长及字典，不能将方格数量误填为内角点数量

默认示例中的长度只用于界面初始展示，实际标定必须填写测量所得的标定板尺寸

内参与手眼样本采集都使用同一块标定板定义，不允许在未清空样本的情况下改变方格尺寸、字典或角点对应关系

采样前检查 RGB 图像中 CharUco ID 是否稳定，避免反光、运动模糊或角点过少

手眼采样时保持机器人静止，增大末端旋转方向与视角覆盖范围，改善矩阵可观测性

标定输出为带末端与相机光学 Frame 的刚体变换矩阵，标定板信息只用于推导相对位姿，不决定矩阵的最终 Frame 名称
