# CharUco 标定使用与验证

## 板参数

在相机内参页面选择 CharUco 并保存参数

| 参数 | 示例值 | 含义 |
|---|---|---|
| 方格列数 / 行数 | 14 / 9 | squares 数量，最多 104 个内角点 |
| 方格边长 | 20 mm | 按实物测量，打印缩放会影响平移尺度 |
| Marker 边长 | 15 mm | 必须小于方格边长 |
| 字典 | DICT_5X5_100 | 必须与实物编码一致 |
| 最少角点数 | 6 | 支持局部可见，角点必须不共线且有足够像素间距 |
| 图案兼容开关 | false | OpenCV 4.6 前生成的偶数行板可能需要开启 |

20 / 15 mm 是示例，不代表已确认你们实物的尺寸

## 采集流程

1. 连接相机，确认板上角点及编号能正确显示
2. 保存板参数，再采集内参图像，覆盖画面边缘、多个距离和多个倾角
3. 内参完成后保持相机分辨率、镜头焦距和对焦状态不变
4. Eye-in-hand 时固定标定板，移动机械臂并绕至少两个方向旋转
5. 每次采集前停稳；自动模式要求接收位姿时间差不超过 80 ms、帧和位姿不超过 0.5 秒、至少 0.3 秒稳定观测，位置波动不超过 2 mm、旋转不超过 1 度
6. 手动输入 xyz 使用 m，四元数顺序 xyzw，关节输入仍使用配置机器人模型
7. 保存 samples.yaml，再运行 Diagnose、Robust / OpenCV / BA、Verify

自动配对采用主机单调时钟的接收时间，不是相机曝光时间或硬件同步；不支持机械臂持续运动时进行精确同步采集

内参图像或外参样本未清空时，板参数、相机、分辨率、位姿来源和输出目录保持锁定；需要更换时先清空相关采集

## 数据与误差

- samples.yaml schema_version 为 2，保存板配置、角点 IDs、2D 角点及采集内参快照
- 每帧 IDs 与二维角点顺序严格对应，不按角点数量猜测板上位置
- 内参逐图误差、PnP 误差和 BA 误差均为逐角点二维 RMS，单位 px
- BA 优先使用采集时保存的内参快照；显式传入不同内参会拒绝优化
- 不含板类型的棋盘 YAML 仍可读取，但已有误差字段无法可靠判断计算口径，建议重新采集或按原始角点重新计算
- BA 暂仅支持 eye_in_hand，使用固定内参联合优化相机相对末端和标定板相对基座位姿
- BA 失败会返回失败状态，不将未精化结果标成 BA；界面不显示上次求解结果作为本次结果
- PnP 检查所有角点正深度并检测近似等误差的不同姿态候选；被拒绝时增大板倾角、覆盖范围或改善图像质量

## 验证命令

```bash
python3 -m pip install -r requirements.txt
npm test
npm run smoke:renderer
```

测试覆盖真实 OpenCV 检测、局部遮挡和旋转 ID 对应、偶数行图案、变点数内参恢复、完整 BA 恢复已知手眼矩阵、无效配置、会话锁定、过期帧和运动拒绝以及 JSON bridge 的 CharUco 采集保存

模拟标定测试不等于真机精度验收；部署前仍需确认实物板尺寸、机器人位姿坐标系、实际相机模式和真机独立验证点
